# Community Server Manager

A Windows control panel for running game servers on one machine or several.

## Download

Get the newest installer from the [Releases](../../releases/latest) page.

## Install

1. Run the installer on the machine that will host the panel and choose "Primary panel".
2. Enter your license key when asked.
3. To add another machine, run the same installer there and choose "Agent node".

## Update

Run the newest installer over the existing install. Your servers and settings are kept.

## Requirements

- 64-bit Windows 10, Windows 11, or Windows Server 2016 or newer
- A license key
